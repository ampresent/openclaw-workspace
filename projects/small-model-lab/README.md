# Small Model Lab — 小模型本地实验

## 目标
在有限硬件（无 GPU、3.4GB RAM、2 核 CPU）上探索本地部署小参数量 LLM 的可行性，建立可复现的部署流程和性能基线。

## 背景
- Google 于 2026-04-03 发布 Gemma 4 系列，引发对本地小模型部署的兴趣
- 当前服务器硬件受限，无法运行 30B+ 级模型
- 目标：验证 1-3B 参数模型在纯 CPU 环境下的推理能力边界

## 范围
### 包含
- 小模型（≤3B）的本地部署与推理测试
- 不同量化级别的性能对比
- 多语言（中/英）推理质量评估
- 与 OpenClaw 的集成可能

### 不包含
- GPU 相关部署
- 微调 / fine-tuning
- 超过 3B 参数的模型
