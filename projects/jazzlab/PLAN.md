# JazzLab 项目规划

## 设计理念

**目标用户**：爵士乐学习者、钢琴/吉他手、业余和专业音乐人
**核心价值**：一个工作台覆盖爵士练习的方方面面，不需要在多个 app 之间切换
**设计风格**：暗色主题 + 金色点缀，专业感但不冷冰冰

## 当前状态 (v0.1.0)

已完成的核心模块：
- ✅ 互动钢琴（2 八度 + 键盘映射 + 和弦/音阶高亮）
- ✅ 和弦库（30+ 和弦类型）
- ✅ 音阶库（25+ 音阶/调式）
- ✅ 吉他指板（15 品，和弦/音阶可视化）
- ✅ 摇摆节拍器（多拍号 + Swing + Tap Tempo）
- ✅ 听音训练（和弦性质/音程/和弦进行）
- ✅ 标准曲库（15 首 + 和弦进行播放）
- ✅ 练习日志（计时器 + 笔记）
- ✅ 乐理指南（和声/调式/重配和声/即兴技巧）
- ✅ 五度圈（交互式）

## 迭代计划

### v0.2.0 — 音色与伴奏
- [ ] 多音色选择（电钢琴 Wurlitzer/Rhodes、贝斯、吉他）
- [ ] 自动伴奏引擎（Swing Bass + Comping pattern）
- [ ] ii-V-I 练习器（选调 → 自动伴奏 → 跟着即兴）
- [ ] 简易鼓机（Ride cymbal + Hi-hat + Kick/Snare pattern）

### v0.3.0 — 学习辅助
- [ ] Transcription Helper（音频上传 → 慢速播放 → AB 循环）
- [ ] Chord Voicing 展示（Shell, Drop 2, Drop 3, Block chords）
- [ ] 更多标准曲（目标 50+）
- [ ] 和弦进行生成器（随机 ii-V-I 练习）
- [ ] Sight Reading 练习（随机和弦/音阶指法速认）

### v0.4.0 — 进阶功能
- [ ] MIDI 键盘/控制器支持
- [ ] 录音 + 回放
- [ ] 练习统计仪表板（每日/每周练习时间、各模块分布）
- [ ] 导入/导出练习数据（JSON）
- [ ] 自定义和弦进行创建
- [ ] 共享曲库（在线同步）

### v1.0.0 — 完整版
- [ ] PWA 支持（离线可用）
- [ ] 多语言（中文/英文/日文）
- [ ] 主题系统（深色/浅色/自定义）
- [ ] 完整的移动端适配
- [ ] 性能优化（音频引擎升级为 AudioWorklet）

## 技术债务

- 音频引擎需要更精细的 ADSR 包络
- 标准曲的和弦解析需要更健壮的 parser
- 听音训练的答案选项生成需要改进（避免重复）
- 吉他指板的 voicing 需要更智能的指法生成

## 已知问题

- Tap Tempo 在长时间间隔后可能不准
- 音阶播放的节奏不统一（固定间隔而非基于 BPM）
- 标准曲播放器的和弦到音的映射较简单
