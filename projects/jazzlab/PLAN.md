# JazzLab 项目规划

## 设计理念

**目标用户**：爵士乐学习者、钢琴/吉他手、业余和专业音乐人
**核心价值**：一个工作台覆盖爵士练习的方方面面，不需要在多个 app 之间切换
**设计风格**：暗色主题 + 金色点缀，专业感但不冷冰冰
**架构原则**：纯前端单页应用，零依赖，浏览器打开即用

## 当前状态 (v0.2.0)

### 已完成模块 ✅
- **互动钢琴**（2 八度 + 键盘映射 + 和弦/音阶高亮 + 多振荡器丰富音色）
- **和弦库**（30+ 和弦类型，按分类筛选，12 根音）
- **音阶库**（25+ 音阶/调式：教会调式、旋律小调、和声小调、对称、Bebop）
- **吉他指板**（15 品，和弦/音阶可视化，点击发声）
- **摇摆节拍器**（多拍号 + Swing + Tap Tempo + 节拍环可视化）
- **Comping 节奏模式库**（8 种经典伴奏节奏型，可播放）
- **听音训练**（4 模式：和弦性质/音程/和弦进行/II-V-I 辨调）
- **标准曲库**（22 首 + 和弦进行播放 + 搜索/筛选）
- **练习日志**（计时器 + 笔记 + localStorage 持久化）
- **乐理指南**（和声/调式/Voicing/重配和声/即兴技巧）
- **五度圈**（交互式 + 调性和弦关系）

### 技术规格
- index.html: ~1856 行（HTML + JS 一体化）
- style.css: ~916 行
- 音频引擎：Web Audio API（多振荡器 + 低通滤波 + 压缩器）
- 存储：localStorage（练习记录）
- 零外部依赖（字体除外）

## 技术债务 & 已知问题

- 音频引擎需要更精细的 ADSR 包络
- 标准曲的和弦解析需要更健壮的 parser
- 听音训练的答案选项生成需要改进（避免重复）
- 吉他指板的 voicing 需要更智能的指法生成
- Tap Tempo 在长时间间隔后可能不准
- 音阶播放的节奏不统一（固定间隔而非基于 BPM）
