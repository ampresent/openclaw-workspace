# JazzLab — 爵士练习工作台

一个面向爵士乐爱好者和练习者的全面 Web 应用，集成和弦/音阶参考、互动钢琴、摇摆节拍器、听音训练、标准曲库等功能。

## 功能模块

### 🎹 互动钢琴
- 两个八度的虚拟钢琴（C3-B4）
- 电脑键盘映射（A-L 白键，W-E-T-Y-U 黑键）
- 和弦/音阶高亮可视化
- 实时 Web Audio 发声

### 🎵 和弦库
- 30+ 种爵士和弦类型（大七、属七、小七、减七、增七、挂留等）
- 按分类筛选（大/属/小/减/增/挂留）
- 12 个根音自由切换
- 点击播放和弦声音

### 🎼 音阶库
- 教会调式（7 个模式）
- 旋律小调体系（7 个模式）
- 和声小调
- 对称音阶（全音阶、减音阶）
- Bebop 音阶
- 五声音阶、布鲁斯音阶
- 点击播放音阶上行

### 🎸 吉他指板
- 标准调弦（EADGBE）15 品指板
- 可视化和弦指法和音阶指型
- 点击品位发声

### 🥁 摇摆节拍器
- BPM 范围 40-300
- 拍号支持：2/4, 3/4, 4/4, 5/4, 6/8, 7/8
- Swing Feel：Straight / Light / Medium / Hard / Shuffle
- Tap Tempo（自动检测速度）
- 可视化节拍环

### 👂 听音训练
- **和弦性质识别**：随机播放和弦，选择正确类型
- **音程识别**：听两个音，判断音程距离
- **和弦进行识别**：听一组和弦，判断进行类型
- 正确率/连续正确数统计

### 📖 爵士标准曲库
- 15+ 首经典爵士标准曲
- 完整和弦进行（含段落标注）
- 按曲式筛选（AABA / ABAC / AB / Blues）
- 搜索功能
- 播放和弦进行

### 📝 练习日志
- 练习计时器
- 按类型分类记录
- 本地持久化存储

### 📚 爵士乐理指南
- II-V-I 进行详解
- 三全音替代
- Voice Leading
- 副属和弦
- 调式理论
- 重配和声技巧
- 即兴演奏方法论

### ⭕ 五度圈
- 可视化五度圈
- 点击调性查看相关和弦
- 关系小调
- II-V-I 进行推荐

## 技术栈

- **纯前端**：HTML + CSS + JavaScript，无需构建工具
- **Web Audio API**：实时合成音色（三角波 + 低通滤波）
- **本地存储**：localStorage 持久化练习记录
- **响应式设计**：支持桌面和移动端

## 运行方式

直接用浏览器打开 `index.html` 即可，或使用任何静态文件服务器：

```bash
cd projects/jazzlab
python3 -m http.server 8080
# 访问 http://localhost:8080
```
