一切皆为源码。系统状态由本地 Git 仓库树和 Patch 栈定义。没有裸二进制，没有黑盒。

工作流

命令错误即开发 — 报错不是终点，是进化的起点

📦 初始化

从 Rocky Linux src.rpm 提取源码，自动 git init + 初始 commit。
evo init vim

🔧 修改源码

直接编辑 src/ 下的文件。修改自动纳入 git 跟踪。

📋 生成 Patch

git diff 自动生成标准 Patch，编号入栈。
evo patch create vim -m "feat"

⬆️ 同步上游

下载新 src.rpm，重置 base，自动 re-apply Patch 栈。冲突高亮。
evo rebase vim

命令速查

evo — 你的系统是一棵活的源码树

evo init <pkg> 从 Rocky src.rpm 初始化包源码
evo status TUI 看板 — 包状态、Patch 栈、构建进度
evo build [pkg] rpmbuild / make，自动应用 Patch
evo patch create/list/drop/show Patch 栈管理 — 编号、diff、回滚
evo rebase [pkg] 上游同步 — Patch 自动 re-apply + 冲突检测
evo tag --create <name> 系统快照 — 记录每个包的 git HEAD + Patch 栈
evo freeze 暂停进化 — 退化为只读 Linux
