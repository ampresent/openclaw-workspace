# 搜索经验与技巧

## 通用规则

### 1. 关键词要多组覆盖，不能只搜一组

**❌ 错误**：只搜「四川航空 套票 2026」就下结论说没有
**✅ 正确**：每个对象至少用 3-5 组不同关键词组合搜索

**案例**（airline-passes 任务）：
| 轮次 | 关键词 | 结果 |
|------|--------|------|
| 第 1 轮 | 四川航空 套票 2026 | ❌ 没找到 |
| 第 2 轮 | 川航 畅飞天府 畅飞 | ❌ 没找到 |
| 第 3 轮 | 四川航空 "想飞就飞" OR "随心飞" OR "畅飞" 2026年 | ⚠️ 找到学生卡 |
| 第 4 轮 | 川航 "优享飞" 随心飞 套票 价格 | ✅ 找到 2024-11 和 2025-11 产品 |

**教训**：航司产品名称每年变，同一个产品在不同平台叫法不同（优享飞 / 优享中国 / 权益卡），必须用多个同义词搜索。

### 2. 不要只看当前在售，要搜历史产品

**❌ 错误**：搜「2026 四川航空 套票」→ 没找到 → 报告"没有产品"
**✅ 正确**：同时搜「2025 四川航空 套票」「四川航空 套票 历史」「川航 优享飞」

**为什么**：了解历史产品可以：
- 预判下一期产品何时上线（通常在换季节点）
- 对比价格走势
- 了解产品规则演变

### 3. 信息源要多渠道，不能只看一类

**❌ 错误**：只搜航司官网和新闻
**✅ 正确**：同时覆盖以下渠道

| 渠道 | 优势 | 适用场景 |
|------|------|---------|
| 航司官网/APP/小程序 | 一手信息 | 确认在售产品 |
| 什么值得买 (smzdm.com) | 优惠聚合，有用户实测 | 发现产品 + 使用体验 |
| 淘宝百科 (bk.taobao.com) | 产品详情解析 | 了解产品细节 |
| 微博/小红书 | 用户讨论，最新消息 | 追踪新品传闻 |
| 美团/飞猪/携程 | OTA 平台有时独占产品 | 发现独家销售 |
| 微信公众号/搜狗搜索 | 航司官方宣传 | 发现新品发布 |

### 4. 搜索结果不确定时，标注「未找到」而非「没有」

**❌ 错误**：「四川航空 ❌ 未找到套票产品」（暗示不存在）
**✅ 正确**：「四川航空 ⚠️ 未找到，需扩大关键词搜索」（承认搜索可能有遗漏）

## 搜索自检清单

每次搜索完成后，对照检查：

- [ ] 关键词是否用了 ≥3 组不同组合？
- [ ] 是否搜了历史产品（不只当前在售）？
- [ ] 是否覆盖了 ≥3 种不同渠道（官网 + 社区 + 社交媒体）？
- [ ] 结论是「未找到」还是「确定没有」？区分清楚
- [ ] 是否遗漏了相关对象（同类型其他品牌/竞品）？
