# Prism 🔮 · 做真实的自己

MTF 身体表达与气质塑造平台 —— 不做手术、不吃药，全方位关注身体的每一步改变。

## 模块

| 模块 | 功能 |
|------|------|
| 🏠 今日概览 | 打卡天数、流程进度、训练记录、皮肤状态、穿搭快览 |
| 🎤 声音训练 | 实时音高监测、共鸣训练（4种练习）、训练日志、发声技巧库 |
| 🧴 护肤管理 | 晨间/夜间护肤流程引导、皮肤状态追踪、产品架管理 |
| 💄 妆容档案 | 妆容记录（风格/技巧/满意度）、化妆技巧库（遮瑕/眼妆/眉毛/腮红等） |
| 👗 穿搭灵感 | 每日穿搭记录、体型穿搭指南（宽肩/腰线/腿型/配色/配饰） |
| 🧍‍♀️ 形体仪态 | 靠墙站立/开肩/猫牛式/走路姿态/坐姿训练、拉伸柔韧练习 |
| 🏋️‍♀️ 身体锻炼 | 5套训练计划（全身/臀腿/腰腹/上身/瑜伽）、训练日志 |
| 📋 每日流程 | 可自定义的晨间/夜间 routine、每日打卡统计 |
| 📓 身体日记 | 身体感受记录、关注区域标记、变化追踪 |
| 🤝 社群花园 | 匿名经验分享（声音/护肤/化妆/穿搭/锻炼） |
| 📚 资源库 | YouTube频道、社区、App、书籍推荐 |
| 💜 情绪支持 | 情绪记录、呼吸练习、每日肯定、自我关怀清单、危机热线 |

## 快速开始

```bash
cd projects/prism
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 隐私

- 所有数据仅存储在浏览器 localStorage
- 不连接任何服务器，不上传任何数据
- 支持导出/导入 JSON 备份
- 离线可用（Service Worker）
