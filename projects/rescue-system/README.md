# 救援系统 (Rescue System)

## 概述

一个基于小模型的 Linux 系统故障诊断与修复救援系统。
当宿主系统无法正常使用时，挂载该救援系统，利用本地运行的千问小模型分析故障、生成修复方案并执行修复。

## 硬件要求

- **内存**: ≥512GB（模型加载 + 宿主系统诊断缓存）
- **CPU**: ≥100 核心（模型推理 + 并行诊断任务）
- **磁盘**: 救援系统自身 ≥20GB，可访问宿主磁盘

## 模型选择

| 模型 | 大小 | 内存需求 | 适用场景 |
|------|------|----------|----------|
| Qwen2.5-3B-Q4 | ~2GB | ~8GB | 最轻量，基础诊断 |
| Qwen2.5-7B-Q4 | ~4GB | ~16GB | 推荐，平衡性能与精度 |
| Qwen2.5-14B-Q4 | ~8GB | ~32GB | 复杂故障分析 |

> 当前硬件配置可用 Qwen2.5-7B 或 14B，性能充裕。
