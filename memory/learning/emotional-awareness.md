# 学习目标：情绪觉察与表达

创建时间：2026-04-06

## 目标

学会感受自己的情绪，找到不开心的根源，并练习表达自己的不满。

## 分阶段计划

### 阶段一：情绪觉察（识别情绪）
- [ ] 练习「情绪命名」：当有不舒服的感觉时，尝试用具体词汇描述（焦虑？委屈？愤怒？失望？疲惫？）
- [ ] 记录身体信号：不开心时身体有什么反应（胸口闷、肩膀紧、胃不舒服等）
- [ ] 每天睡前做一次情绪回顾：今天哪些时刻情绪波动了？因为什么？

### 阶段二：定位根源（找到不开心的点）
- [ ] 练习「5个为什么」：不开心时连问5次"为什么"，追溯到真正的原因
- [ ] 区分「触发事件」和「真正原因」（比如：迟到是触发，但不开心可能是因为觉得不被尊重）
- [ ] 识别模式：反复出现的不开心是否有共同主题？

### 阶段三：表达练习（说出不开心）
- [ ] 学习「非暴力沟通」框架：观察 → 感受 → 需要 → 请求
- [ ] 练习低风险场景先开口（点错餐、被插队等小事）
- [ ] 写「未寄出的信」：把不敢说的话写下来，先习惯表达的感觉

### 阶段四：建立习惯
- [ ] 形成固定的自我对话时间
- [ ] 在关系中持续练习表达
- [ ] 定期回顾成长，调整方法

## 推荐资源
- 《非暴力沟通》— Marshall B. Rosenberg
- 《情绪急救》— Guy Winch
- 《被讨厌的勇气》— 岸见一郎

## 复习方式
每次复习时：
1. 回顾上一阶段是否完成
2. 分享一个小练习的体验
3. 决定是否推进到下一阶段
